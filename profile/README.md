# NV OSE

Welcome to the GitHub home of **NV OSE — The Office of State Epidemiology**.
We use this space to share training materials, code, templates, and project resources.

## Our repositories

| Repository | Purpose | Visibility |
|---|---|---|
| [`training`](https://github.com/nv-ose/training) | Workshops, tutorials, and learning materials (published at `https://nv-ose.github.io/training`) | Public |
| [`shared-resources`](https://github.com/nv-ose/shared-resources) | Internal reusable code, templates, scripts, and project materials (members only) | Private |
| [`presentations`](https://github.com/nv-ose/presentations) | Conference talks, posters, briefings, and webinars | Private (public once cleared) |
| [`team-hub`](https://github.com/nv-ose/team-hub) | Internal discussions, Q&A, and announcements (members only) | Private |
| Project repos | One repo per major project | As needed |

## Contributing

Everyone adding content must follow our **[Contributing Guidelines (SOP)](https://github.com/nv-ose/.github/blob/main/CONTRIBUTING.md)**. It covers:

- Repository and file naming conventions
- Standard folder structures
- Required README and metadata
- Branching, commits, and review
- What should never be uploaded
