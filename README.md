# .github

This public repository holds the nv-ose organization's:

- **Public profile page:** [`profile/README.md`](profile/README.md), shown at [github.com/nv-ose](https://github.com/nv-ose)
- **Contributing Guidelines (SOP):** [`CONTRIBUTING.md`](CONTRIBUTING.md), which applies to every repo in the organization

Members see a fuller, member-only page from the private [`.github-private`](https://github.com/nv-ose/.github-private) repo.

## Suggesting changes

- **To the SOP:** open an Issue or a pull request in this repo. SOP changes are approved by an owner; update the version and date at the top.
- **To the public profile:** pull request, approved by an owner. Remember this page is **public**: don't list private repos or internal details here.
